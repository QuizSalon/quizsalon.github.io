PRIVACY POLICY

Last updated: November 11, 2026

This policy covers the Quiz Salon website and Quiz Salon Uploader, a private tool that uses YouTube API Services. By using Quiz Salon Uploader you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Who uses the uploader

Quiz Salon Uploader is used only by the owner of the Quiz Salon YouTube channel, to manage that channel. It is not available to the public.

What data it accesses

With the channel owner's permission, the uploader uses YouTube API Services to upload Quiz Salon videos and thumbnails, set their titles, descriptions, tags, privacy and schedule, and read the channel's own list of uploads to confirm they succeeded. It does not access, collect or store data about viewers or any other YouTube users.

How data is stored

The sign-in token that Google issues is stored only on the channel owner's own computer. Video files and their details are kept on that computer and sent only to YouTube. Quiz Salon does not run servers that store this data, and it does not use cookies or tracking on this website.

Sharing

Quiz Salon does not sell, share or transfer any data obtained through YouTube API Services to anyone else.

Revoking access

Access can be revoked at any time on the Google security settings page: myaccount.google.com/permissions. Deleting the stored token from the owner's computer also ends the uploader's access.
